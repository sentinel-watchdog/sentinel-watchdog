# Sentinel Watchdog branding

The emblem combines a vigilant watchdog with a shield to represent service
supervision and infrastructure protection. Navy, teal and white provide
contrast; the image contains no lettering so it can serve as a tool or
repository avatar.

The canonical logo now lives in the separate `sentinel-watchdog-design`
project. This repository keeps a local export for its README. The initial
export was transferred unchanged on 2026-10-06; no design release tag exists
yet. Future updates must record the design tag or commit here. See
[project boundaries](project-layout.md).

## Asset and usage

- [Transparent PNG](../assets/branding/sentinel-watchdog.png), 1254 × 1254
  pixels, with an alpha channel.
- Use the square image for tool icons, repository avatars and documentation.
- Keep its aspect ratio and the existing margin; avoid stretching it.
- On dark backgrounds, check the navy outline for sufficient contrast.
- This is a raster asset; no editable vector master is included.

## Generation provenance

Created on 2026-10-06 using the built-in image generation tool, with
`transparent_background: true`. The generated PNG was copied into the
repository without image modifications. No new runtime dependency was
introduced.

Final prompt:

> Use case: logo-brand. Asset type: square app icon and repository emblem for Sentinel Watchdog, an open-source Linux infrastructure monitoring and network-security tool. Create one polished original minimalist logo: a vigilant watchdog head seen from the front, geometrically integrated into a strong shield silhouette. Calm, alert, protective expression, pointed ears, bold clean shapes and intentional negative space; professional infrastructure software identity. Flat vector-like graphic, deep midnight navy with a restrained teal accent. Center the single emblem on a truly transparent background, with generous safe margins for avatar cropping. Designed to remain legible at small icon sizes. No text, no letters, no wordmark, no gradients, no shadows, no texture, no 3D, no mockup, no extra symbols, no watermark. Output a finished icon, not a design sheet.
